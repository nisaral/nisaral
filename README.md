## Research

- **[DIO](https://github.com/nisaral/DIO)**: LLM serving scheduler. p99 latency −33% vs round-robin on real T4/A30 GPUs, 5 seeds. DOI [10.5281/zenodo.22085398](https://doi.org/10.5281/zenodo.22085398)
- **[Soro-Kev / Soro-Boro](https://github.com/nisaral/Soro-Boro)**: calibrated small-model tool-call router. 90.58% on an external held-out set.
- **[falsesafe-bench](https://github.com/nisaral/falsesafe-bench)**: false-safe errors in HJ reachability with learned dynamics. Epistemic inflation at k=2 cuts false-safe volume by 40.3% (preregistered; the ≥50% target was not met).
- **[uncertainty-diffusion-world-models](https://github.com/nisaral/uncertainty-diffusion-world-models)**: an identifiability result for uncertainty distillation in diffusion world models.
